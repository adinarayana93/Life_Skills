# Good Practices for Software Development

## Question 1

### Which point(s) were new to you?

- Asking clear questions with the problem, what I tried, and useful screenshots or code.
- Sharing all questions in one message instead of sending many messages.
- Using group channels for communication so the whole team has context.
- Informing the team early when a problem may affect the deadline.

## Question 2

### Which area do you think you need to improve on? What are your ideas to make progress in that area?

I need to improve my communication when I get stuck. I will explain the problem clearly, mention what I tried, and share the relevant code or screenshots. I will also communicate early when I face delays or blockers instead of waiting too long.
